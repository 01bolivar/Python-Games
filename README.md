# Python-Games
Python Games

This is a collection of mini games i developed in order to practice my python skills.

About
the file includes 4 different games:
-Snake Game: the classic game, a snake moving around and eating the random placed food to grow, controlled by the arrow keys, it gets destructed by touching itself or the wall, and keeps track of player's all time high score
-hangman: another classic, gives you a random word and you have to try to guess it by trying out letters, you can see the man getting hanged with a little graphic every time you fail to guess
-Pong: a classical ping pong/table hockey game, made as multiplayer, the first player controls by arrow keys, and second by "W""A""S""D", while keeping the score on
-Turtle Crossing: trying to pass a turtle across the road while obstacles drive by, goes on for several levels, each level the random obstacles speed up, plays by the up arrow key.


Each project has its separate source file, and show a pathway of improvement.
